# Архитектура основы проекта

Этот документ описывает техническую основу `base-ui`: как связаны Tailwind, shadcn, токены, шаблоны и bootstrap новых проектов.

## Архитектура

1. `DESIGN.md` описывает тему, дизайн, цвета, типографику и UX-правила.
2. `src/index.css` хранит CSS variables и Tailwind theme tokens.
3. `components.json` фиксирует shadcn-настройки и алиасы.
4. `src/lib/utils.ts` содержит `cn` для безопасного объединения классов.
5. shadcn-компоненты добавляются только через отдельное решение и используют существующие токены.
6. Шаблоны страниц собирают готовые блоки, а не хаотичные наборы классов.

## Tailwind и токены

Tailwind-классы можно копировать между проектами только если вместе с ними переносится общая основа: CSS variables, `@theme inline`, `components.json`, `cn` и правила из `DESIGN.md`.

Предпочтительный подход:

* использовать семантические токены: `bg-background`, `text-foreground`, `border-border`, `bg-card`, `text-muted-foreground`;
* не завязывать компоненты на случайные одноразовые цвета;
* расширять токены сначала в `src/index.css`, затем использовать их в компонентах;
* сохранять радиусы, отступы и состояния предсказуемыми.

## shadcn

shadcn - это не внешняя UI-библиотека, которую приложение импортирует как готовый пакет компонентов. CLI копирует код выбранных компонентов в репозиторий, после чего этот код становится частью проекта.

Правило для этого репозитория:

* `shadcn init` и `components.json` разрешены как базовая настройка;
* `shadcn add ...` выполнять только после явного решения;
* каждый добавленный компонент должен быть нужен конкретному шаблону или повторяемому UX-сценарию;
* после добавления компонента нужно проверить, что он использует токены дизайн-системы.

## Минимальная база нового проекта

Минимальная база означает не "поставить все возможные UI-компоненты", а подготовить воспроизводимый фундамент:

* Vite React TypeScript project;
* Tailwind CSS configured;
* shadcn initialized;
* `components.json` configured;
* CSS variables added;
* `cn` utility added;
* `DESIGN.md` copied;
* `AGENTS.md` copied.

shadcn-компоненты не входят в минимальную базу. Они добавляются отдельными итерациями.
