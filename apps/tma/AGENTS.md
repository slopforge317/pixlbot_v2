Этот репозиторий создан для создания и управления единой системой дизайна и UX для будущих проектов. Его цель - собрать готовые токены, компоненты, шаблоны страниц и элементы, которые можно переиспользовать во множестве проектов. В данном репозитории хранится Интерфейс Telegram Mini App по генерации фото с помощью нейросетей.

### Технический стек

* TypeScript
* package manager: pnpm
* Tailwind CSS - 4.3.2
* shadcn - 4.12.0
* Radix UI - 1.6.1
* React - 19.2.7
* React DOM - 19.2.7
* Vite - 8.1.0
* Node.js - v24.18.0 LTS



### Правила

1. В репозитории должны быть только целенаправленно добавленные shadcn-компоненты.
2. Нельзя добавлять новые shadcn-компоненты без явного разрешения.
3. Если нужен новый shadcn-компонент, сначала предложить его и объяснить зачем.
4. Не копировать хаотичные Tailwind-классы между проектами. Переиспользовать токены, `cn`, готовые шаблоны и целевые компоненты.
5. Tailwind-токены и CSS variables являются источником правды для визуальной системы.
6. `DESIGN.md` используется только для описания темы, дизайна, цветов, типографики, визуальных токенов и UX-правил.
7. Техническую архитектуру Tailwind/shadcn и правила минимальной базы смотри в `docs/project-foundation.md`.
8. При чтении файлов документации используй обязательно кодировку UTF-8
```powershell
Get-Content -Encoding utf8 DESIGN.md
```
9. при запуске браузера не запускай сам сервер, а просто открывай сразу `localhost:5173` и только если эта страница не доступна, попроси пользователя запустить dev сервер

### Документация

* `DESIGN.md` - тема, цвета, типографика, визуальные токены и UX-правила.
* `docs/project-foundation.md` - архитектура основы проекта, правила Tailwind/shadcn, минимальная база.
* `docs/new-project-bootstrap.md` - пошаговая инструкция для создания нового проекта на базе `base-ui`.
* `docs/tailwind-token-reuse.md` - инструкция по переиспользованию tailwind классов и список креализованных классов.
