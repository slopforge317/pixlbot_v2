# Заметки по реализации

## Решения

- Селектор TMA показывает `Provider.title` как публичную модель. Внутренние `AIModel.title` больше не выводятся отдельными пунктами.
- Без референса выбирается `text_only`, с референсом — `image_required`; `image_optional` подходит для обоих случаев.
- Параметры строятся из `input_schema`, сортируются по `ui_order`, получают defaults и участвуют в выборе pricing variant.
- Старые `values` поддерживаются frontend, но seed нормализует их в `options` с `value`, `label`, `sort_order` 10/20/30.
- Prompt и поле reference images имеют отдельные UI-блоки; остальные string/boolean параметры выводятся динамически без новых shadcn-компонентов.

## Допущения

- Текущий этап не отправляет реальную генерацию: существующая кнопка prototype сохраняет прежнее локальное поведение. Upload и POST generation требуют отдельного этапа интеграции.
- При переключении Text-to-Image/Image-to-Image сохраняются только значения, допустимые новой схемой; остальные заменяются defaults.

## Риски и продолжение

- Frontend пока поддерживает одно reference image, хотя Nano Banana допускает несколько.
- Для полного E2E генерации потребуются рабочие KIE/S3 credentials и подключение кнопки к upload/create-generation API.
- В DOM добавлены `data-selected-provider` и `data-active-api-model` для проверки автоматического переключения без показа технического API ID пользователю.
- Визуальная browser-проверка не выполнена: `localhost:5173` не был запущен, согласно правилам проекта dev server автоматически не запускался.
