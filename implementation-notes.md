# Заметки по реализации

## Решения

- Badge `Pro`/`Basic`/`Basic*` больше не отображается в TMA. Backend-поле `status` пока сохранено для совместимости API.
- Цена показывается как точная стоимость выбранного pricing variant с русским склонением слова «кредит».
- Reference images хранятся массивом. Лимит количества и размер каждого файла берутся из `max_images` и `max_image_size_mb` выбранной публичной модели.
- Для модели с лимитом одного изображения новый файл заменяет старый. Для моделей с большим лимитом файлы добавляются до ограничения.
- Prompt использует `max_length` текущей внутренней реализации; при переключении на меньший лимит текст обрезается до допустимой длины.
- Backend проверяет prompt и reference arrays по `input_schema` модели, связанной с pricing variant. Также проверяется соответствие присланной модели pricing variant.

## Найденные ограничения каталога

- Nano Banana 2: до 14 фото, 30 MB каждое, prompt до 20000 символов.
- Nano Banana Pro: до 8 фото, 30 MB каждое, prompt до 20000 символов.
- Seedream 5 Lite: до 1 фото, 10 MB; prompt 2995/2996 символов.
- Seedream 4.5: до 1 фото, 10 MB; prompt до 3000 символов.
- GPT Image 1.5: до 1 фото, 10 MB; prompt до 3000 символов.
- Общий S3 upload limit увеличен с 10 до 30 MB, иначе разрешённые Nano Banana файлы отклонялись бы backend.
